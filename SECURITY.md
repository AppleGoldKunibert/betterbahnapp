# Security

If you find a security problem in the app or in the Cloudflare Workers (for example a way around
App Attest, a leaked key, or a way to use the proxies from outside the app), please report it
privately instead of opening a public issue:

- via GitHub's [private vulnerability reporting](../../security/advisories/new), or
- by email to goldkunibert@gmail.com.

Please include what you found and how to reproduce it. Thanks!
