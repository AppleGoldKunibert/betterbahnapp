# BetterBahn for Android

Prototype of the Android app (#467): BetterBahnKit built with the Swift SDK for Android, UI in Kotlin/Compose.

1. `kit/build.sh` (macOS, Linux or WSL2) builds the Kit into `app/src/main/jniLibs/`.
2. Open this folder in Android Studio and run the app on an emulator.

Details, what's missing and how both apps stay in sync: [`docs/android.md`](../docs/android.md).
